# Brollary · 空镜库

**Brollary（空镜库）** 是一款本地优先的素材库管理器，为设计师、剪辑师和所有被素材淹没的人而生：把散落各处的图片、视频、音频、字体、LUT 收进同一个地方，让它们**可浏览、可搜索、可复用**。

> 名字来自影视行业的 B-roll（空镜 / 补充镜头）：**B-roll + Library = Brollary**。

## 核心特性

- **🗂️ 一切素材，一个库** —— 图片、GIF、视频、音频、字体、LUT、工程文件统统收纳，瀑布流一屏浏览，悬停即播放。
- **🎨 按颜色找素材** —— 你记住的往往不是文件名，而是画面。内置拾色器：取一个颜色，找出库里主色调相近的所有素材（基于感知均匀的色差模型，找到的就是"看起来像"的）。
- **🔍 快到无感的搜索** —— 索引化全文检索，文件名、标签、注释即输即得，中文开箱即用；万级素材依然流畅。
- **🧠 智能文件夹** —— 把常用筛选条件存成"会自动更新的文件夹"，比如「所有 wav 音效」「所有 1080p 以上的横版视频」，条件支持组合嵌套。
- **🧬 重复文件扫描** —— 按内容（而非文件名）识别重复素材，逐组预览、一键清理，腾出磁盘空间。
- **🕸️ 网页一键采集** —— 浏览器扩展：看到喜欢的图，右键收藏或批量勾选入库；来源网址自动记录，永远知道素材从哪来。
- **🔌 开放本地接口** —— 应用内置本地 API，任何本机脚本、自动化流程、第三方工具都能往库里推素材。
- **♻️ 误删不怕** —— 删除先进回收站，随时一键恢复；重复扫描默认也只移入回收站，安全第一。
- **📚 多库管理** —— 新建空库、添加现有 `.library` 素材库、或直接导入文件夹，随时切换。

## 数据属于你

这是 Brollary 与其他素材管理器最根本的不同：

- **库就是一个普通文件夹**（`你的素材库.library`），里面是原始文件 + 人类可读的 JSON 元数据。没有私有数据库、没有加密，用任何文本编辑器都能打开。
- **索引只是加速层** —— 检索用的索引可以随时删除重建，权威数据永远是文件本身。换电脑、备份、迁移，复制文件夹即可。
- **不静默丢数据** —— 个别文件元数据损坏时，会保留现场并明确报告原因，绝不悄悄丢弃。

## 快速开始

环境要求：macOS + Node.js ≥ 26

```bash
git clone https://github.com/bokix/brollary.git
cd brollary
npm install
npm start          # 启动桌面应用
```

首次启动后：**新建空库**，或**添加已有 `.library` 素材库**，或**直接导入文件夹**。

### 命令行（可选）

除图形界面外，Brollary 附带命令行工具，适合脚本化与批量操作：

```bash
node src/cli.ts import "<库路径>.library"   # 导入 / 增量更新索引
node src/cli.ts stats                       # 库总览
node src/cli.ts search "关键词"             # 全文检索
node src/cli.ts tag "标签名"                # 按标签浏览
node src/cli.ts color "62,99,221"           # 按颜色检索
node src/cli.ts dedup                       # 重复扫描
node src/cli.ts restore <条目ID>            # 从回收站恢复
```

## 浏览器扩展

支持 Chrome / Edge（Manifest V3）：

1. 打开 `chrome://extensions`，开启「开发者模式」
2. 点「加载已解压的扩展程序」，选择仓库中的 `extension/` 目录
3. 首次使用请在扩展「选项」页确认端口

- 图片右键 → **收藏到 Brollary**：单张入库，角标 ✓/✗ 反馈
- 工具栏弹窗：列出当前页所有图片，勾选批量入库，默认标签自动记住上次输入

## 本地 API

应用启动后监听 `http://127.0.0.1:41596`（端口可通过环境变量 `STASH_API_PORT` 修改，被占用时自动顺延）。

安全设计：只绑定本机回环地址，并拒绝来自网页的跨站请求——浏览器中的恶意页面无法调用，本机的 curl / 脚本 / 扩展不受影响。

```bash
# 探活
curl http://127.0.0.1:41596/api/ping

# 从网址采集（来源页自动记录到条目）
curl -X POST http://127.0.0.1:41596/api/item/add -H 'content-type: application/json' \
  -d '{"url":"https://example.com/a.png","website":"https://example.com/page","tags":["网页采集"]}'

# 从本地文件采集（复制进库，不动源文件）
curl -X POST http://127.0.0.1:41596/api/item/add -H 'content-type: application/json' \
  -d '{"path":"/Users/me/Downloads/a.png","tags":["下载"]}'

# 轻量列表
curl 'http://127.0.0.1:41596/api/item/list?limit=20&q=关键词'
```

## 设计承诺

1. **不锁定** —— 开放格式，随时可以离开，数据原样带走。
2. **不静默** —— 出错就明说，损坏就报告，绝不悄悄吞掉你的素材。
3. **可重建** —— 索引永远可以从原始数据重建，缓存坏了不算事。
4. **安全优先** —— 删除先进回收站，破坏性操作永远不在默认路径上。

## 开发者速览

- 技术栈：Electron + TypeScript（严格模式）；媒体管线内置 ffmpeg / ffprobe（视频探针、缩略图、色板提取）
- 架构：JSON 文件为权威源，SQLite / FTS5 为可随时重建的检索索引；颜色搜索基于 CIELAB 色差 + 色板索引
- 实测参考：888 条素材全量导入约 99ms，0 损坏
- 开发代号 `stash`（目录名与 CLI 沿用）；相关文档见 `../FEATURE-MATRIX.md`（功能规划）与 `../LIBRARY-FORMAT.md`（`.library` 格式规格）
