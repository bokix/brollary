Features

该有的都有，
还有你没见过的。

从采集、组织到检索、复用——Brollary 把素材管理的每一步都做扎实。

一切素材，一个库

图片、GIF、视频、音频、字体、LUT、工程文件统统收纳。瀑布流一屏浏览，悬停即播放，再也不用在一堆文件夹里翻箱倒柜。

按颜色找素材

你记住的往往不是文件名，而是画面。内置拾色器：取一个颜色，找出库里主色调相近的所有素材——找到的就是「看起来像」的。

CIELAB 色差 · 色板索引

快到无感的搜索

索引化全文检索，文件名、标签、注释、来源 URL 即输即得，中文开箱即用。万级素材，依然毫秒级响应。

SQLite + FTS5 · 索引可重建

智能文件夹

把常用筛选条件存成「会自动更新的文件夹」：所有 wav 音效、所有 1080p 以上的横版视频……条件支持组合与嵌套。

重复文件扫描

按内容（而非文件名）识别重复素材，逐组预览、一键清理，腾出磁盘空间。清理默认只进回收站，安全第一。

网页一键采集

浏览器扩展：看到喜欢的图，右键收藏或批量勾选入库。来源网址自动记录，永远知道素材从哪来。

Chrome / Edge · Manifest V3

开放本地接口

应用内置本地 HTTP API，只绑定回环地址、拒绝跨站请求。任何本机脚本、自动化流程、第三方工具都能往库里推素材。

curl 127.0.0.1:41596/api/ping

误删不怕

删除先进回收站，随时一键恢复；重复扫描默认也只移入回收站。破坏性操作，永远不在默认路径上。

多库管理

新建空库、添加现有 .library 素材库、或直接导入文件夹，随时切换。外置盘、网络盘不可用时优雅降级，绝不报错甩脸。

Color Search

你记住的不是文件名，是画面。

取一个颜色，Brollary 基于感知均匀的色差模型，找出主色调相近的所有素材。下面这个迷你演示，就是真实体验：

选中一个颜色试试 👇
相似的素材会立刻亮起来。

每个素材入库时都会提取主色板（RGB + 占比）。检索时用 CIELAB 色差计算相似度——不是机械的 RGB 距离，而是「看起来像」的那种相似。

Your Data

数据属于你。
字面意义上的。

1

库就是一个普通文件夹

里面是原始文件 + 人类可读的 JSON 元数据。没有私有数据库、没有加密，用任何文本编辑器都能打开。

2

索引只是加速层

检索索引可以随时删除重建，权威数据永远是文件本身。换电脑、备份、迁移，复制文件夹即可。

3

不静默丢数据

个别文件元数据损坏时，会保留现场并明确报告原因，绝不悄悄丢弃你的素材。

你的素材库.library — 所见即所得 
你的素材库.library/          # 就是一个普通文件夹
├── metadata.json          # 文件夹树、智能文件夹、标签组
├── tags.json              # 标签状态
├── backup/                # 库级元数据自动快照
└── images/
    └── MT89NPKT183JM.info/  # 每个素材一个目录
        ├── metadata.json
        ├── 海边落日.mp4        # 原始文件，原样保存
        └── 海边落日_thumbnail.png

# metadata.json — 人类可读，任何编辑器都能打开

Promises

四条设计承诺，写进代码里。

不锁定

开放格式，随时可以离开，数据原样带走。

不静默

出错就明说，损坏就报告，绝不悄悄吞掉你的素材。

可重建

索引永远可以从原始数据重建，缓存坏了不算事。

安全优先

删除先进回收站，破坏性操作永远不在默认路径上。
